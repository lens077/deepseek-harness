# Agent Note: 任务流程中的认证安全投影

Status: implemented

[English](2026-09-06-task-flow-auth-message-projection.md) | 中文

## 问题

提供方认证错误可能回显凭据片段。任务流程终态节点如果复制提供方消息，即使其他对话渲染器显示安全的认证提示，输入框上方的流程条或流程视图仍可能暴露这些片段。

## 决策

终态错误码为 `AUTH` 时，[任务流程投影](../../../../packages/client/ui-task-flow/src/client/flow-model.ts)省略原始消息。节点保留明确的 `failureCode`，共享格式化函数为此错误码渲染本地化的 API 密钥无效提示。其他错误消息保留既有行为。

此规则将[有界 LLM 请求恢复](../architecture/2026-06-21-bounded-llm-request-recovery.zh.md)描述的安全认证展示策略应用于任务流程消费者，不修改 Session 日志、提供方诊断或模型可见数据。

## 考虑过的替代方案

**仅在渲染时遮蔽消息。** 否决，因为原始消息仍会留在 `FlowSnapshot` 中，可被每个消费者及未来的渲染变体读取。

**在详情字段中使用哨兵字符串。** 否决，因为认证哨兵可能与其他错误的原样消息冲突。独立的失败码保留了两者的区别。

## 影响

任务流程消费者在终态节点中不会收到原始认证消息，用户仍可看到失败类别及可执行的本地化提示。这是仅针对 `AUTH` 的投影规则，不是适用于所有错误或日志内容的通用清理器。

## 验证

专门的模型回归测试断言任务流程快照不含认证消息。组装后的 Web AUTH 场景保留凭据片段不得出现的断言，而不是将提供方文本接受为预期输出。
