# Agent Note: 汇总工作区布局与运行详情

Status: implemented

[English](2026-09-26-digest-workspace-layout-and-running-work.md) | 中文

## 问题

只有运行中会话的汇总需要把空间用于这些会话，而不是空状态列。卡片底部不齐和不限高度的工作区栏使信息难以浏览。仅有最初的提问，也无法说明 agent（智能体）正在做什么或已经记录了多少工作。

## 决定

[汇总面板](../../../../packages/client/ui-digest/README.zh.md)只为有内容的状态分配空间。仅有一种状态时，两种布局都使用完整的卡片网格。汇总面板设置可将每行卡片数设为一至八列，默认五列。浏览器本地偏好限制最多列数；可用内容宽度不足时减少列数，保持 240px 的可读最小宽度，更窄的容器使用单列全宽卡片。对齐的卡片边缘与操作行保持逐行阅读顺序。键盘提示位于滚动内容之外。这取代了[看板决策](2026-09-22-digest-board-layout-and-reply-toggle.zh.md)中的空列分配与页脚位置，但保留其分组、手机行为和收尾结果偏好。

本功能向既有的布局设置 slot 贡献工作区偏好，并共享面板的浏览器本地视图存储。默认单行，支持横向滚动和鼠标拖动。两至六行的限制只约束最大高度，不预留空行。显示全部取消行数限制；相对视口的滚动限制仍为卡片保留空间。临时展开不改变保存的偏好或当前筛选。只有位移越过阈值，拖动才抑制随后的点击。

运行卡片读取既有的 Host 全局会话投影与可见后台任务快照。agent 任务及清单计数描述当前列表；步骤和工具总数明确标为累计。优先使用本会话记账，完整日志统计回退会说明包含继承历史。缺少数据不等于零进度。最新记录是已提交的可见助手文本，不是推理内容或逐 token 输出，也可能早于自动继续轮次。后台任务对该会话可见，可能包含未归属任务。不需要新增历史订阅、模型调用、会话事件或重启 Host。

键盘选择在重新排序后仍保留会话身份。每张桌面卡片都常显可用按钮的 1–6 提示，使快捷键映射始终可见；外框标识这些键实际操作的唯一卡片。紧凑的按钮内边距和键帽让操作按文字及卡片可用宽度自然换行，不裁剪标签。原生控件保留 Enter、Space 和焦点遍历。分组跳转的 Tab 到达任一端时恢复原生遍历，只有一个分组时也如此；键盘用户不会被困在无法触达筛选的位置。这取代了[键盘决策](2026-09-23-digest-panel-keyboard-triage.zh.md)中的循环行为，不改变空间方向键或可配置卡片操作。

## 备选方案

**保留空状态列以固定位置。** 当一种状态包含全部会话时，固定位置没有帮助，反而减少卡片的可用宽度。采用有内容状态的稳定相对顺序。

**使用瀑布流或占位卡片填满空白。** 瀑布流会分离视觉与键盘顺序，占位内容没有工作信息。等宽卡片网格保留真实会话数和阅读顺序。

**订阅全部会话历史以显示精确的当前工具文本。** 既有推送投影已经包含任务、提交后的更新和累计记账。新增订阅会使打开汇总的成本随全部保留历史增长。精确的当前步骤或工具执行声明需要独立、受限且可信的投影，不能由尚未匹配结果的调用推测。

**通过 Host 设置同步行数偏好。** 此偏好服务于一个浏览器的视口，与既有的浏览器本地看板和结果可见性偏好放在一起，不引入服务端 schema 或修改权限要求。

## 后果

结果开关隐藏收尾回答，但保留运行详情。工作区过多或占高过大时，即使选择显示全部，也在栏内滚动；卡片视口过短时通过滚动保持操作可达，而不是裁剪控件。显式打开会话即可查看完整记录。[选择规则测试](../../../../packages/client/ui-digest/tests/select.client.spec.ts)、[工作区测试](../../../../packages/client/ui-digest/tests/workspace-filter.client.spec.tsx)、[工作量测试](../../../../packages/client/ui-digest/tests/work-summary.client.spec.ts)和[浏览器场景](../../../../apps/web/tests/digest-layout.e2e.ts)覆盖非空状态、溢出交互、准确记账与真实卡片几何。[录制导航场景](../../../../apps/web/tests/navigation-panes.e2e.ts)负责已完成汇总的输出。
