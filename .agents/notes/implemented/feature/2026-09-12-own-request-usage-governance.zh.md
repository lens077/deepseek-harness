# Agent Note: 本会话请求用量与提醒式成本治理

Status: implemented

[English](2026-09-12-own-request-usage-governance.md) | 中文

## 问题

仅凭 token 总量无法回答哪个模型消耗预算、重试是否增加流量，或 fork 是复用还是生成了继承历史。跨父子会话累加全日志数据会重复计入继承请求。缺失用量和可选缓存分桶可能让看似精确的价格低于已观察工作所需金额。操作人员还需要无需检查或导出内容的工具与前缀诊断。

## 决策

既有 session-stats 插件新增 `usageLedger` 投影。它统计 Session 自身的 Assistant 结算和已上报用量的压缩摘要请求，精确排除继承前缀。每次持久尝试结算都分别累加，包括没有重试插件事件的直接恢复重试；同一结算的组装用量与嵌入用量是替代关系，不是两次请求。计时必须有已记录的开始时间，不会复用前一次失败尝试的区间。推理仍包含在输出中。逻辑用量步骤和上报请求分别计数，因此重试和压缩流量不会虚构 agent 步骤。

部署提供精确的提供方／模型价格、币种和可选的不重叠 UTC 循环分层。折叠保存周内小时分桶，并在生成视图时使用当前价格表，包括恢复的检查点。缺失或矛盾的用量、无法对齐的提示词分桶以及缺少路由价格均抑制完整估价。wire 解析器强制校验币种和完整性。冷会话或尚未加载的行保持缺失，不按零处理。这些估价是持久快照诊断，不是提供方账单或按历史生效日期计价的账本。

Web 输入框保留既有时间 pill，以成本优先的用量 pill 打开响应式抽屉。抽屉聚合本会话、仅含子代理的后代树，或当前可用的非空会话。它按持久 id 去重，不将普通 fork 加入子代理树。列表不完整、缺少账本、币种混合或计费数据不完整时，抑制总成本和预算判断。当前会话的部署策略控制选中的统计范围。

预算和满足样本门槛后触发的浪费线索仅用于提醒，不会取消、降级或改路由。检测覆盖平均输入、缓存命中、首 token 占比、重试频率、工具错误和请求前缀变化。首 token 样本门槛按实际测量请求数判断。前缀比较使用有效系统内容、已组装工具 schema 和路由，不使用采样参数。提示词、schema 原文、工具参数和结果内容不会进入账本视图。抽屉限制键盘焦点、使应用背景 inert、关闭后恢复触发按钮焦点，并支持移动端安全区。

本金额统计决策部分取代[隐私安全可观测性](2026-08-24-privacy-safe-harness-observability.zh.md)中延期的成本方案，其 exporter 隐私规则仍独立有效。[Token 投影](../architecture/2026-07-29-projected-token-usage-and-request-context.zh.md)继续负责上下文压力和精确的逐轮用量。[输入框 pill](2026-09-07-composer-session-stats-pills.zh.md)保留时间／用量分组与输入框间距，成本治理由更完整的用量抽屉负责。三篇记录均未被完全取代，也不归档。

## 考虑过的替代方案

**跨会话累加 token-meter 投影。** 不用于支出统计，因为全日志投影包含继承事件，且没有价格分配与完整性元数据。它仍是诊断回退，不是计费来源。

**把缺失缓存分桶或失败请求按零处理。** 否决。提供方精确总量可证明省略的分桶为零；仅凭省略无法证明。发送前取消的步骤也可能保守地隐藏估价，而非声称成本为零。

**在每个列表行持久化逐步骤成本时间线。** 否决。时间线随会话增长，并重复不可变日志细节。按路由划分的循环小时分桶与运维聚合提供有限维度；完整历史定价和时间线需要另设有界查询。

**通过中断或切换模型强制预算。** 本功能不采用。软诊断不能根据滞后快照、不完整提供方报告或可配置估价安全地决定执行行为。

## 后果

该功能在本地运行，不需要 collector、账号、新的模型可见事件或修改已发布 Session 格式。价格不确定性会明确显示，已知流量仍可排查。它无法统计未进入持久结算的提供方工作，包括未记录的标题调用、没有摘要事件的失败摘要请求、外部工具账单和结算前的进程丢失。UTC 循环定价不包含历史价格变更、税费、提供方余额或量价协议。

## 验证

定向投影与 Loader 测试固定重试结算、退避取消、缺失用量、可选分桶对齐、fork 归属、内容排除、schema 拒绝、分层边界、配置失败与检查点重估行为。客户端测试固定聚合完整性、样本门槛、预算和焦点限制。真实装配的 Web E2E 测试覆盖本会话／会话树／全部范围、冷会话与继承会话、不完整或未定价流量、键盘行为、移动布局和可重复的无障碍输出。
