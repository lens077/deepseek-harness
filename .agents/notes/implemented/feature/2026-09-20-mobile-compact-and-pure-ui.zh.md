# Agent Note：移动端紧凑布局与纯净 UI

Status: implemented

English | [English](2026-09-20-mobile-compact-and-pure-ui.md)

## Problem

移动端 Web GUI 将过多空间交给会话顶部栏和输入框。打开或切换会话还会自动聚焦编辑器，导致手机键盘弹出并改变阅读位置。文件、日志和面板控件也挤占了回答内容空间。

## Decision

输入框在挂载、解锁和会话切换时不再自动聚焦。移动端工具按钮和模型选择器保持单行；模型名称从开头省略并优先保留末尾字符。输入框默认紧凑，展开按钮可将草稿滚动区扩大到约 45dvh，并使用内部滚动条。

移动端将统计信息放到流程标签后的同一行。打开文件、会话日志、右侧面板角落按钮以及会话面板切换按钮在手机上隐藏。顶部栏和标签栏减少间距，并保持控件单行显示。

主题设置拥有默认值为 `false` 的 `pureUi` 布尔字段。该字段通过现有 `ui-theme` 设置域持久化，同时出现在通用设置行和手机齿轮左侧的纯净 UI 按钮中。布局根节点发布 `data-pure-ui`。纯净 UI 隐藏会话顶部栏和停靠输入框，将当前提问以左上角纯文字显示，并在右下角提供浮动按钮按需展开输入框；已选中的交互覆盖层仍保持挂载。

## Alternatives considered

**只在桌面保留自动聚焦。** 拒绝，因为请求明确要求取消打开会话时的聚焦行为，统一规则也能避免设备差异带来的焦点竞争。

**为纯净 UI 新建状态存储。** 拒绝，因为主题已有稳定的展示可观察值，侧边栏可直接消费该来源。

**复用侧栏底部动作槽放置手机按钮。** 拒绝，因为该槽同时属于桌面侧栏，手机专用动作不应依赖无关的底部组合。

**在手机上删除统计信息。** 拒绝，因为轮次、步骤和 token 仍然有价值；放到流程标签旁边即可避免增加输入框高度。

## Verification

ui-theme、ui-sidebar、ui-layout、ui-conversation、ui-chat 和 ui-model-selection 的定向测试通过。客户端 TypeScript 项目和 UI 国际化校验通过。变更过的客户端包均成功打包。390px 和 1280px 的本地 Playwright 截图验证了紧凑标签、手机展开状态、纯净 UI 顶部栏隐藏、纯文字提问和浮动输入按钮。

GUI 全量测试中，变更行为通过，但仍报告两个无关的既有失败：tool-call-tree fixture，以及 ui-theme AppearanceRow 样式的圆角扫描。依赖校验器也仍报告 ui-session-files 的既有清单问题。

## Consequences

纯净 UI 只改变展示，不新增会话事件、模型可见输入、线路操作或会话持久记录。手机标签栏新增了声明槽位，生成的 Client catalog 必须继续与 ui-conversation 合同同步。用户始终可以从设置或手机顶部按钮恢复完整界面。
