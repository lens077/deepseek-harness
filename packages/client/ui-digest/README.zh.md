# @deepseek-ai/dsh-client-ui-digest

[English](README.md) | 中文

跨工作区收件箱界面。位于「新会话」与工作区浏览区之间的 **汇总** 入口携带待处理计数——有多少会话在等你回复、失败了、或完成但未读——并切换一个覆盖中间栏的面板，面板有三个标签：**收件箱**、**待办**、**时间线**。`Ctrl+1` 可从任何位置开关同一个面板：该入口在整个会话期间都挂载，因此由它持有这个组合键；组合键带修饰键，所以在输入框和面板自己的输入框里同样有效。

收件箱回答的是「哪些事需要我，以及为什么」，一次覆盖全部工作区。行按需要关注的原因分区，顺序就是早上分诊想要的顺序：**置顶**、**等你回复**（Agent 卡在审批或提问上）、**失败 / 中断**（最后一轮以 `completed` 之外的方式结束，或从未结束）、**完成未读**（回复落在用户上次已读标记之后）、**已读未处理**（打开过但未标记已处理）、**运行中**，以及按需显示的 **已处理**。等你回复、失败、未读与置顶的行不受时间窗限制；时间窗（**自上次查看**、**今天**、**近 7 天**、**全部**）只约束上下文行。延后的行只计数不列出。分区上方的工作区 chip 携带每个工作区的待处理数与运行中数，可把视图收窄到一个工作区或未分组的工作。

每张卡片显示状态徽标、会话与工作区、最新的人类提问、收尾回答，以及该轮改动的文件，并提供键盘环也能触达的操作：**打开会话**、**继续**（打开会话并在输入框预填一行接续语）、**标记已处理**、**加入待办**、**置顶**、**明天再看**（延后到次日 09:00）。键盘环按分区顺序遍历卡片——`j`/`k` 移动、`Enter` 打开、`e` 已处理、`t` 加入待办、`p` 置顶、`s` 延后、`Escape` 关闭——因为都是单字母，会忽略在可编辑控件中键入的按键。**标记已查看** 把「自上次查看」的起点移到现在；**复制晨报** 把当前分区与未完成待办以 Markdown 放入剪贴板。

待办标签列出用户的待办及其指向的会话与提问，提供 **跳到那一问**（通过 ui-conversation 的 `chatReveal` 座位把会话对话滚动到该提问）、**继续**、完成与删除，并可从输入框添加关于当前会话的待办。其下，最后一轮未正常完成的会话以自动待办的形式出现，带打开、继续与已处理操作。会话浏览区的右键菜单通过本包提供的 `sessionTodos` 座位为选中的会话提供 **加入待办**。时间线标签把每个会话保留的每一条提问放在它被提出的那一天，最新在前，并可在该提问处打开会话。

## 数据

卡片内容全部随会话列表下发：每一行携带宿主的 [`sessionDigest`](../../session/session-digest/README.zh.md) 投影值，因此打开面板不发起会话请求，也能显示本浏览器从未附着过的会话。用户的标记——已读 seq、已处理、延后、置顶、查看时间与待办——来自宿主的 [`sessionInbox`](../../session/session-inbox/README.zh.md) Remote，经由一个控制器：加载时读一次，每次变更回复和转发的 `session-inbox/changed` 推送都会整体替换，连接重置后重新读取。已读标记由本插件负责：只要当前会话最新落地的 seq（回复；未回答时为提问）在屏幕上，就把该 seq 记录到宿主，因此「我不在时完成了」是持久事实，而不是刷新即消失的小圆点。待处理计数还会上报到 ui-renderer 的 `documentBadge` 座位，前缀到浏览器标签页标题。

归档会话、空白会话与子代理来源的行永不出现。提问与回答文本按宿主配置的预算截断；回答被截断的卡片会说明并指向会话。

## 组合

```yaml
- id: ui-digest
  name: '@deepseek-ai/dsh-client-ui-digest'
```

通过 `slots.inject()` 注册进由其他包声明的两个座位——`sidebar.nav.entry`（[ui-sidebar](../ui-sidebar/README.zh.md)）与 `center.overlay`（[ui-layout](../ui-layout/README.zh.md)）。两处注册共享 `apply` 中创建的同一个视图 store（打开、标签、时间窗、工作区筛选、已处理可见性）与同一个收件箱控制器。注入 `remote.sessionInbox`；缺少宿主的 `sessionDigest` 单元时面板照常组合，只是报告没有需要处理的内容。本包提供 ui-workspace 消费的 `sessionTodos` 座位，并读取可选的 `chatReveal`、`conversation` 与 `documentBadge` 座位。

## 模型体验

无。收件箱属于浏览器界面外壳，此处没有任何内容进入模型请求。

#### KV 缓存影响

无；本包既不组装也不发送提供方请求。

## 已知限制与遗留工作

- **每个会话一张卡片** —— 卡片显示最新提问及其回答；更早的提问出现在时间线上，但没有回答。
- **超过配置预览长度的回复不完整展示** —— 宿主已截断的回答把用户引导至会话，而不是拉取每一份已列出的历史。
- **已读标记跟随选中而非阅读** —— 打开会话即把其最新回复标记为已读，无论用户是否滚动到它。
- **延后时间固定** —— 唯一的延后选项是到次日本地时间 09:00。
- **面板打开时覆盖整个中间栏** —— 它是界面切换而非分栏视图。
