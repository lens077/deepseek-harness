# @deepseek-ai/dsh-client-ui-digest

[English](README.md) | 中文

## 概述

跨工作区查看已完成、运行中、失败和等待回复的会话。跟进 agent（智能体）的当前任务清单和记录更新，再打开会话、添加待办、置顶或标记已处理。在布局设置中配置工作区筛选行数，不预留空行。汇总使用既有摘要，不逐个加载完整记录；预览不会把回答标记为已查看。

## 使用本包

跨工作区收件箱界面。位于「新会话」与工作区浏览区之间的 **汇总** 入口携带各状态的会话计数——等待你选择（警示色）、完成未读（即 **已完成** 分区，成功色）、运行中（蓝色）、出错（错误色），顺序由 **汇总面板** 设置页决定，并可选加上一个灰色的「已完成（已读）」计数；每个角标只在计数非零时显示，侧栏折叠后只保留一个角标，显示总和，颜色取当前存在的第一个状态——并切换一个覆盖中间栏的面板，面板有四个标签：**收件箱**、**待办**、**项目待办**、**时间线**。一个快捷键——默认 `Ctrl+1`，可在 **汇总面板** 设置页录制成别的——可从任何位置开关同一个面板：该入口在整个会话期间都挂载，因此由它持有这个快捷键。含 Ctrl / Alt / ⌘ 的组合键在输入框和面板自己的输入框里同样有效；打字就能打出的快捷键（单个按键，或 Shift 加一个键）只在可编辑区域之外生效。

收件箱回答的是「哪些事需要我，以及为什么」，一次覆盖全部工作区。行按需要关注的原因分区，顺序就是早上分诊想要的顺序：**置顶**（用户明示的优先级，排在最前；运行中的置顶行仍留在 运行中）、**已完成**（回复落在用户上次已读标记之后）、**已读未处理**（已确认查看但未标记已处理）、**运行中**（正在进行的工作）、**等你回复**（Agent 卡在审批或提问上）、**失败 / 中断**（最后一轮以 `completed` 之外的方式结束，或从未结束），以及按需显示的 **已处理**。运行中、等你回复、失败、未读与置顶的行不受时间窗限制；时间窗（**自上次查看**、**今天**、**近 7 天**、**全部**）只约束上下文行。延后的行只计数不列出。分区上方的工作区 chip 携带每个工作区的待处理数与运行中数，可把视图收窄到一个工作区或未分组的工作。

工具栏上的 **分区** / **看板** 开关选择桌面端排布。分区纵向排列有内容的状态；看板按决定顺序横向排列有内容的状态列：**等你决定**、**已完成**（合并未读与已读）、**运行中**、**失败 / 中断**。空状态不占位。只有一种状态时，两种排布都使用整个内容宽度；各行靠上排列，按内容决定高度，不为填满视口而拉长少量卡片。**设置 → 汇总面板 → 每行卡片数** 可为每个分区或单状态看板选择 1–8 列，默认 5 列。空间不足时自动减少列数，尽量保持每张卡片至少 240px 宽；容器更窄时使用单张全宽卡片。此偏好保存在当前浏览器，不改变工作区筛选；卡片边缘与操作行对齐。多个看板列各自滚动。置顶行留在所属状态列，已处理行按结果归入已完成或失败。**显示结果** 控制收尾回答及截断提示，不隐藏运行详情；关闭结果时提问压缩为两行。两项偏好按浏览器保存。手机保留紧凑的单列分区，小布局在 **更多操作** 内提供结果开关。

桌面端每张卡片显示状态徽标、会话与工作区、最新的人类提问、收尾回答，以及该轮改动的文件——提问与回答在限高的卡片正文内滚动，卡片共享对齐的行高——并提供键盘环也能触达的操作：**打开会话**、**继续**（打开会话并在输入框预填一行接续语）、**标记已处理**、**加入待办**（把该行移入待办：同一提问已有未完成待办时复用而不重复创建，并把会话标记为已处理，卡片随之离开收件箱）、**置顶**、**明天再看**（延后到次日 09:00）。各行分别按内容决定高度，卡片正文没有独立的固定高度上限。卡片高度上限参考内容视口，并以 240px 作为上限的下界，保证短窗口中的控件可用。头部和操作行位于滚动正文之外；窗口容不下卡片时，外围内容区可以滚动。操作按钮按实际文字与可用宽度自然换行，压缩横向内边距和键帽留白，不固定为每行两个。键盘提示位于滚动区之外的紧凑页脚。每次打开面板时，键盘环默认选择第一张可见卡片，再按分区顺序遍历卡片，看板下则逐列遍历：`j`/`k` 沿环移动，`Home`/`End` 跳到两端；方向键按屏幕位置沿行（`←`/`→`）或沿列（`↑`/`↓`）移动——焦点卡片正下方有卡片时进入下一个分区，看板下则去到旁边那列并排的卡片——到行或列的边缘即停；`Tab`/`Shift+Tab` 跳到下一个或上一个非空分组的第一张卡片；到达两端或控件持有焦点时，恢复原生焦点遍历，可到达工具栏和工作区筛选；`Enter` 执行 **汇总面板** 设置页里选定的卡片操作（默认 **打开会话**），焦点卡片没有该操作时改为打开会话；`Shift+Enter` 始终打开会话；数字键 `1`–`6` 按顺序按下卡片的按钮，所有桌面卡片都在可用按钮旁常显对应数字，外框标识按键实际操作的唯一卡片；`Escape` 关闭。数字键同时也是侧栏置顶区的默认快捷键，因此面板在收件箱标签打开期间会在捕获阶段先接住它们。面板打开时会从按下开关快捷键的位置接过焦点，按键因此落到面板而不是被盖住的输入框，关闭时再把焦点还回去；所有按键在可编辑控件内都不生效。**标记已查看** 把「自上次查看」的起点移到现在；**复制晨报** 把当前分区与未完成待办以 Markdown 放入剪贴板。任何显式 Session 导航都会关闭面板，包括再次点击左侧栏中已选中的会话行；被动恢复 selection 不会关闭面板。

待办标签列出用户的待办及其指向的会话与提问，提供 **跳到那一问**（通过 ui-conversation 的 `chatReveal` 座位把会话对话滚动到该提问）、**继续**、完成与删除，并可从输入框添加关于当前会话的待办。其下，最后一轮未正常完成的会话以自动待办的形式出现，带打开、继续与已处理操作。会话浏览区的右键菜单通过本包提供的 `sessionTodos` 座位为选中的会话提供 **加入待办**。时间线标签把每个会话保留的每一条提问放在它被提出的那一天，最新在前，并可在该提问处打开会话。

项目待办标签列出宿主 [`projectTodos`](../../todo/project-todos/README.zh.md) 扫描在配置的根目录与每个已注册工作区下找到的待办文档（`TODO.md` 等）：每个项目目录一个分区，带来源与未完成/已完成计数；每个文档一个区块，列出条目（复选框状态、嵌套，悬停显示所属小节），超过八条折叠。每个文档提供 **在此项目新建会话**（必要时把目录注册为工作区，在其中打开会话，并在输入框预填一行指向该文档的提示）、**查看原文**（通过 Remote 读取并内联显示文档文本）与 **用系统应用打开**；每个项目提供 **打开目录**。**重新扫描** 让宿主立即扫描，**只看有未完成项的项目** 隐藏已全部完成的项目，扫描结果在标签首次显示时读取。本包同时在既有设置分区旁贡献三个设置页：**汇总面板**（面板开关快捷键——在只读输入框里按下即保存，按键不受支持或在 Ctrl/⌘ 下属于编辑或浏览器时拒绝并说明原因；收件箱里 `Enter` 执行的卡片操作；是否在入口右侧显示状态角标、是否加上灰色已完成角标、角标顺序——拖动行或用上移/下移按钮调整；基于节点侧注册的 `ui-digest` 设置节；存储值若是录制器会拒绝的快捷键，则按默认值读取）、**项目待办**（带目录选择器的根目录列表、文件名规则、是否包含工作区；基于 `project-todos` 设置节）与 **置顶**（基于 `session-pins` 设置节：**启用置顶**——默认开启，关闭后隐藏卡片动作及其 `5` 键、收件箱的 置顶 分组、会话浏览区的菜单项与侧栏置顶区，标记本身保持持久化；**侧栏置顶区**、其 **显示会话数**——**自适应** 或 1–20 行，默认 5、侧栏置顶区在置顶标记之外自动列出的 **自动置顶** 状态——进行中、已完成、出错，默认包含进行中和已完成；**汇总面板置顶分组**——关闭后置顶行落回其原本的分组）。侧栏置顶区的 ⋯ 菜单通过 `sessionPins` seat 修改的是同样的两项设置，两处显示同一个值。

手机端**总览**保留四个标签，使用独立的手机标签选择状态，初始为收件箱。运行中的工作排在最前，其计数可切换只看运行中筛选。Workspace 筛选使用同一份行数偏好，初始为可横向滚动的单行。**待处理**依次显示等待审批、计划评审或回答的会话、完成未读的会话，以及既有的个人待办列表。此视图不使用总览的时间与 Workspace 筛选，也不显示失败会话自动待办。两种布局的**加入待办**使用同一份由 Host 持久化的个人待办；项目待办文档仍位于总览的独立标签中。

手机端总览与待处理的会话行初始只显示标题、未读标记和展开控件。点击标题展开提问、回复、文件与操作；同一面板最多展开一条会话。收起时详情与操作不挂载，展开控件通过 `aria-expanded` 和 `aria-controls` 暴露状态与目标。

在手机小布局或高度不超过 500px 的手机视口中，总览将视图与时间范围合并为两个原生选择控件，旁边提供更多操作。更多操作保留运行中筛选、已处理可见性、查看标记与复制操作；较大的布局保留展开的控件。

<a id="reading-and-acknowledgement"></a>
## 阅读与查看确认

自动模式在当前会话最新一条已完成 Chat 回答持续可见 5 秒后标记已查看。实际渲染的回答内容必须在可见且聚焦的页面内处于屏幕上、未被遮挡；只有思考内容可见时不计时。离开回答、页面失去可见性或焦点、回答被遮挡，或收到不同的回复 seq，都会重置计时。多次访问的时间不累加。仅选择会话或历史提问不会把回复标记为已读。

**汇总面板**设置中的 `readAcknowledgement` 可选 `automatic`（默认）或 `manual`，后者要求显式操作。`readGraceSeconds` 将完整的连续等待时间设为 1–60 的整数秒数（默认 5 秒），在数字输入框失去焦点时保存。手动模式禁用等待时间控件；设置不可写时，两个控件均禁用。自动确认要求设置就绪，在加载中或不可用时暂停，不会在这些状态下使用默认值确认回复。收件箱服务可用时，标题栏的显式操作仍可持久化查看确认。

当前会话标题栏在两种模式下都为其未读的已完成回答提供**标记已查看**，包括 Trajectory 视图。该操作只确认这条回复，不把会话标记为已处理，也不改变置顶标记。写入失败会保留未读状态，可通过标题栏操作重试。已读未处理的结果仍按既有收件箱时间窗规则保留显示资格。汇总面板另有一个**标记已查看**操作，它推进查看时间窗，而不确认某一条回复。

<a id="workspace-strip-and-running-work"></a>
## 工作区栏与运行详情

**设置 → 布局 → 汇总工作区栏** 提供 **单行**（默认）、**2–6 行**上限和**显示全部**。行数上限只占用实际标签所需的高度。超出部分仍可滚动；**显示全部**临时展开，不改变已保存的偏好或当前工作区筛选，**收起**恢复上限。单行模式支持鼠标拖动、触屏滑动和原生横向滚动。偏好保存在当前浏览器；无效行数按单行读取。全部展开时仍受视口高度上限约束，超出部分在栏内滚动，不挤走卡片。

运行卡片显示 agent（智能体）的进行中任务及清单计数、最近记录的助手文本、累计步骤和工具调用/返回/失败数，以及该会话可见的运行中或正在停止的后台任务。文本预览和抽样标签有长度与数量限制；未展示的任务、工具名和后台任务仍计入总数。任务清单来自 agent，不是收件箱的个人待办。优先使用本会话记账；回退到完整日志统计时明确说明包含继承历史。缺少投影时省略指标，不声称进度为零，也不把尚未匹配结果的工具调用当作正在运行的工具数。**最新记录**是已提交的可见文本，不是推理内容、逐 token 输出，也不保证来自当前轮次；自动继续期间可保留上一条记录，直到新记录提交。

<a id="data"></a>
## 数据

卡片内容全部随会话列表下发：每一行携带宿主的 [`sessionDigest`](../../session/session-digest/README.zh.md) 投影值，因此打开面板不发起会话请求，也能显示本浏览器从未附着过的会话。运行详情将既有的 `todos`、`usageLedger`、`sessionStats` 投影值与 Host 全局控制流的 `jobsBySession` 合并；面板不为卡片逐个订阅历史。用户的标记——已读 seq、已处理、延后、置顶、查看时间与待办——来自宿主的 [`sessionInbox`](../../session/session-inbox/README.zh.md) Remote，经由一个控制器：加载时读一次，每次变更回复和转发的 `session-inbox/changed` 推送都会整体替换，连接重置后重新读取。本插件只在连续可见时间达到设定值或用户显式确认后记录回复的已读 seq，因此未读状态在刷新后仍保留，不把导航视为阅读。待处理计数还会上报到 ui-renderer 的 `documentBadge` 座位，前缀到浏览器标签页标题。

归档会话、空白会话与子代理来源的行永不出现。提问与回答文本按宿主配置的预算截断；回答被截断的卡片会说明并指向会话。

<a id="composition"></a>
## 组合

```yaml
- id: ui-digest
  name: '@deepseek-ai/dsh-client-ui-digest'
```

侧边栏入口与面板通过 `slots.inject()` 注册进由其他包声明的两个座位——`sidebar.nav.entry`（[ui-sidebar](../ui-sidebar/README.zh.md)）与 `center.overlay`（[ui-layout](../ui-layout/README.zh.md)）。两处注册共享 `apply` 中创建的同一个视图 store（打开、标签、时间窗、工作区筛选、已处理可见性）、同一个收件箱控制器与同一个项目待办控制器。注入 `remote.sessionInbox` 与 `remote.projectTodos`；缺少宿主的 `sessionDigest` 单元时面板照常组合，只是报告没有需要处理的内容。本包提供 ui-workspace 消费的 `sessionTodos` 与 `sessionPins` 座位——后者把置顶 Session id、已完成未处理 Session id（收件箱在「自上次查看」窗口下的 已完成 与 已读未处理 行，使侧栏的已完成自动置顶在 Host 重启后仍在）与 置顶 策略（含区域高度和自动置顶状态）作为一个快照发布，只在其中之一变化时重新发布，通过收件箱控制器置顶或取消置顶，并把高度和状态写入 `session-pins` 设置——读取可选的 `chatReveal`、`chatReplyExposure`、`conversation` 与 `documentBadge` 座位，并在 `settingsScope` 存在后把三个设置页注册进 `settings.section`（[ui-settings](../ui-settings/README.zh.md)）；节点侧在存在设置提供者时注册 `ui-digest` 与 `session-pins` 设置命名空间。当前会话的手动查看确认操作单独注册到 `conversation.session.header.actions`。

<a id="model-experience"></a>
## 模型体验

无。收件箱属于浏览器界面外壳，此处没有任何内容进入模型请求。

#### KV 缓存影响

无；本包既不组装也不发送提供方请求。

## 已知限制与遗留工作
<a id="known-limitations-and-deferred-work"></a>

- **每个会话一张卡片** —— 卡片显示最新提问及其回答；更早的提问出现在时间线上，但没有回答。
- **超过配置预览长度的回复不完整展示** —— 宿主已截断的回答把用户引导至会话，而不是拉取每一份已列出的历史。
- **可见不代表理解** —— 自动确认只观察实际渲染的 Chat 回答，不从汇总卡片预览或 Trajectory 推断。标题栏的显式操作仍可使用；可见时间与已查看标记都不能证明理解，也不代表已处理。
- **延后时间固定** —— 唯一的延后选项是到次日本地时间 09:00。
- **面板打开时覆盖整个中间栏** —— 它是界面切换而非分栏视图。
- **项目待办文档在这里只读** —— 勾选完成意味着编辑文件；宿主的监视器随后刷新该标签。
