# @deepseek-ai/dsh-client-ui-task-flow

[English](README.md) | 中文

## 概述

在输入框上方的紧凑流程条或可平移缩放的「流程」视图中查看会话的任务进度。两处界面从已加载的会话历史中展示提问、插话、后续、todo 进度、委派 agent（智能体）和轮次结果，包括手动停止与失败。流程条在展开图形前概括路线计数、用时和当前活动。两处界面可独立选择卡片、轨道或泳道布局：流程条默认为轨道，画布默认为卡片。尚未加载的更早历史不显示。

<a id="use-this-package"></a>
## 使用本包

将本插件与 `ui-conversation`、`ui-session`、`ui-settings` 和 locale 插件一同挂载；Host 半边在存在 settings 提供者时注册 `ui-task-flow` 设置命名空间。会话在已加载轮次内出现第一条提问后，流程条即出现在输入框上下文堆栈中，「流程」tab 则排在对话视图环里的「轨迹」之后。

宽度小于 768px 时，输入框上方的流程条默认隐藏，除非在通用设置中启用**在手机上显示任务流程**（`ui-task-flow.mobileDock`，默认 `false`）。独立的流程视图仍然可用，桌面流程条的可见性不受影响。Host-backed scope 将此设置持久化到 Host 文档；使用 memory 模式的远程浏览器使用同源 `dsh.task-flow.mobile-dock` 存储，无效存储值重置为 `false`。

### 读图

| 元素 | 含义 |
|---|---|
| 路线 `#n` | 一条已准入的提问，按提问顺序从 1 连续编号：第一条为「主线」；在某轮运行中被准入的为「插话」（挂在当时正在执行的节点下）；上一轮关闭后发出的新问题为「后续」（接在主线最后一个节点之后）。Goal 自动继续会标为「继续执行 #n」；上一轮被中止后原样重发的用户问题标为「重试 #n」。开放轮次内的转向消息画成只有提问节点的插话。 |
| 主干节点 | 该轮最新一次 `todo/write` 的一项，按列表顺序排列，带该项首次进行中与完成的时间；没有 todo 也没有子代理的轮次画成一个覆盖其步骤的「执行」节点，轮次未正常完成时该节点直接写明终态（「已中止」「出错」「异常中断」），记录的原因作为其悬停提示。 |
| 扇出 | 委派子代理调用（默认 `subagent`、`subagent_fork`、`workflow`、`ralph`）堆叠在调用时处于进行中的 todo 之后；失败的子代理把该 todo 标为「有风险」。点击子代理节点在轨迹视图中打开该调用。 |
| 终结节点 | 仅当带 todo 主干的轮次未正常完成时出现：用户取消为「已中止（手动停止）」，其他取消原因、「出错」，或崩溃补齐的「异常中断」。取消用中性色，出错与崩溃用错误色。提问节点始终为中性色，只有其路线运行中时才着色。 |
| 历史芯片 | 流程条以主线上最新的路线开头，把之前的所有路线（及挂在它们上的插话）折叠成一个带状态计数的「历史 n 轮 · …」芯片；点击展开完整流程，「收起历史轮次」再折回去。画布从不折叠。 |
| 头部 | 按状态统计的路线数（进行中、已完成、已中止）；用时——有轮次运行时为本轮时长，否则为已关闭轮次时长之和，不含轮次之间的空闲；开放路线的编号与截短的提问，附正在执行的主干节点及其步数或主干进度；以及开放路线以外的最近插话及其状态。窄布局下先压缩插话，再压缩当前项。 |
| 长文字 | 提问、todo、委派子代理和终结错误文字在节点内换行，不再用省略号隐藏。卡片节点图按换行后的标题为每张卡片定高（按当前字号以字形宽度估算，上限 40 行），同一列按各自高度堆叠；步骤轨道按内容定宽，芯片不会被压缩而互相重叠，宽度由流程条主体滚动或画布平移承接；泳道面板以「箭头 + 节点」为单元按路线换行。提问和委派 agent 的显示标签均以 4,096 个 UTF-16 代码单元为上限；每个节点的悬停提示都带完整显示标签，已中止的执行节点和失败的委派 agent 还带记录的原因。 |

### 控件

折叠开关位于流程条标题之前，向辅助技术提供操作名称和展开状态，悬停或聚焦时不弹出提示。样式菜单切换流程条变体；「在画布打开」选中「流程」视图，其工具栏提供同样的计数、用时、停止、样式和「返回对话」控件，以及缩放按钮和「适配全图」。「停止任务」（会话运行时可见）是头部最后一个操作，取消当前轮次并保留队列。两个变体选择都持久化到 Host 设置文档，并同时出现在通用设置中。「任务流程字号」独立于正文字号控制流程条和画布的文字大小：默认为 11px，可在通用设置中调节为 10px 至 16px。展开后的流程图主体超过 160px 时在内部滚动；窄布局下头部自动换行。

认证失败（`AUTH`）不会将提供方原始错误消息带入任务流程快照，而是显示本地化的 API 密钥无效提示。其他轮次错误保留错误消息与非 `UNKNOWN` 错误码，委派工具错误保留结构化结果码和文字，并显示在节点附注与悬停提示中。此显示策略不改变 Session 日志或模型可见数据。

### 配置

| 字段 | 默认值 | 含义 |
|---|---|---|
| `agentToolNames` | `['subagent', 'subagent_fork', 'workflow', 'ralph']` | 其 `tool/call` 事件画成委派子代理节点的工具名。 |

## 了解实现

<details>
<summary>实现内部 —— 点击展开</summary>

四个事件定义注册到 `task-flow` 视图目标：按消息 id 键控的提问（用户来源的 `user/message`）、按 seq 键控的收件箱准入（含插入消息的 `agent/inbox/spliced`，从匹配位置记录当时开放的轮次）、按 seq 键控的 todo 快照（`todo/write`），以及按调用 id 键控的子代理调用（配置名的 `tool/call`，由 `tool/result` 结算）。视图构建器按 key 保存当前目标节点，并在每次发布时由这些节点与引擎的轮次时间线重新组装快照，因此历史替换、向前翻页和实时追加得到相同结果。插话锚点以准入时间对比主干节点的时间区间得出；后续锚定到主线上一条路线的最后一个主干或终结节点。卡片布局是纯函数：主线及其后续放在同一行，每个主干节点一列，被服务的子代理堆叠在下一列，插话行放在其锚点之下；轨道把同一条主线串成链并把插话挂在下方，泳道面板则每条路线一行。流程条与画布通过会话作用域的 `useTaskFlow` hook 读取快照；流程条的展开标志是按会话持久化的 store；画布变换是组件本地状态。「在画布打开」使用外壳安装的视图打开器 `uiConversation.openView`。

</details>

<a id="model-experience"></a>
## 模型体验

### 任务流程展示与控件

#### 模型看到的内容

无。本包读取现有 Session 事件，包括 `user/message` 和 `turn/end`，不注册提示词段、工具或模型可见消息；停止操作调用现有的对话取消操作。

#### Token 影响

无。绘制流程和切换布局不增加模型输入 token，也不发起推理请求。

#### KV Cache 影响

无。本包不修改请求消息或其缓存前缀。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>


这些限制定义了当前的任务流程界面，是当前包约束而非任务清单。

- **仅限已加载窗口** —— `turn/start` 位于已加载历史页之外的提问在加载更早页面之前不会开启路线；画布不会触发翻页。
- **对话导航** —— 点击提问或 todo 节点不会滚动对话视图；只有子代理节点可导航到轨迹检视器。
- **工作流阶段** —— 不折叠 `tool-workflow/*` 事件；一次工作流运行画成一个子代理节点。
